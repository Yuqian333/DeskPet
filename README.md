# DeskCat 桌面宠物

DeskCat 是一款基于 Android + Jetpack Compose 开发的桌面宠物应用。应用以“陪伴型桌面宠物”为核心，支持宠物养成、互动动作、悬浮窗展示、天气提醒、自定义形象、宠物资源包导入、小游戏和 AI 动画生成等功能。

## 功能特性

- 宠物主界面：展示宠物形象、心情气泡、金币数量和饱腹度、开心值、精力值。
- 基础互动：支持摸摸、喂食、玩耍、休息、拖动宠物和重置位置。
- 状态养成：宠物状态会随互动变化，并会根据离线时间和空闲时间自然衰减。
- 食物商店：内置猫粮、小鱼干、牛奶、罐头、甜点等食物，不同食物有不同价格和属性效果。
- 小游戏：包含接金币小游戏、逗猫棒和食物老虎机，用于获得金币或免费食物。
- 桌面悬浮窗：申请悬浮窗权限后，可以让宠物常驻桌面，支持拖动、贴边收起、展开快捷操作。
- 天气联动：支持手动城市天气和设备定位天气，宠物会根据天气给出提醒并改变心情。
- 自定义形象：支持从本地选择图片作为宠物形象，并使用 ML Kit 分析宠物类型。
- 宠物资源包：支持导入 zip 格式资源包，使用 body、paw_up、paw_down 三张图组合出更自然的动作。
- AI 透明动画：支持调用豆包图片生成接口，根据用户上传的宠物图片生成 3 张关键帧，并组成 `1 -> 2 -> 3 -> 2 -> 1` 循环桌宠动画。
- AI 动画库：生成过的动画会保存为历史版本，支持在设置页管理、切换、重命名和删除，并使用第一帧作为封面。
- 透明背景处理：AI 生成帧会优先使用 remove.bg 抠图，未配置或失败时使用本地白底/浅色背景去除兜底，减少悬浮窗白底遮挡。
- 宠物命名：支持自定义宠物名字，界面、气泡、天气提醒和小游戏反馈会使用用户设置的名字。
- 数据持久化：使用 DataStore 保存宠物状态、金币、互动次数、宠物设置和天气城市配置。

## 技术栈

- Kotlin
- Android Gradle Plugin
- Jetpack Compose
- Material 3
- AndroidX Lifecycle ViewModel
- AndroidX DataStore Preferences
- ML Kit Image Labeling
- Android 悬浮窗服务
- 和风天气接口
- 豆包多模态接口

## 运行方式

1. 使用 Android Studio 打开项目根目录。
2. 等待 Gradle 同步完成。
3. 使用真机或模拟器运行 `app` 模块。
4. 如需使用悬浮窗功能，请在系统设置中授予“显示在其他应用上层”的权限。
5. 如需使用定位天气，请授予定位权限。

## API 配置

天气功能和 AI 动画功能依赖外部接口。不要将真实密钥提交到仓库，建议在 `local.properties` 中配置：

```properties
QWEATHER_API_HOST=你的和风天气 API Host
QWEATHER_API_KEY=你的和风天气 API Key
REMOVE_BG_API_KEY=你的 remove.bg API Key（可选）
DOUBAO_API_KEY=你的豆包 API Key
DOUBAO_API_HOST=ark.cn-beijing.volces.com
DOUBAO_IMAGE_MODEL=doubao-seedream-5-0-260128
DOUBAO_IMAGE_INPUT_FIELD=image
```

天气、抠图和豆包即梦配置会通过 Gradle 写入资源值，再由运行时代码读取；真实密钥只保留在本机 `local.properties`。`local.properties.example` 提供了可复制的配置模板。

AI 动画生成流程：

1. 用户在设置页上传宠物图片。
2. 应用压缩图片并转为 Base64，结合默认或自定义提示词调用豆包图片生成接口。
3. 生成 3 张风格统一、小幅动作变化的关键帧。
4. 应用对返回图片做透明背景后处理，并保存到 `files/ai_anim/sets/`。
5. 主界面和桌面悬浮窗优先播放当前 AI 动画；重启后会自动恢复。

如果豆包接口失败、无图、图片无法解析或图生图字段不被支持，应用会保留原自定义图片展示，并在设置页给出明确错误提示。

## 宠物资源包格式

导入 zip 资源包时，压缩包内至少包含：

```text
body.png
paw_up.png
paw_down.png
```

可选配置文件：

```json
{
  "paw": {
    "xRatio": 0.5,
    "yRatio": 0.82,
    "widthRatio": 0.45
  }
}
```

其中 `xRatio`、`yRatio` 用于控制爪子在身体图上的位置，`widthRatio` 用于控制爪子宽度。

## 主要使用流程

1. 进入应用后，在宠物页查看当前宠物状态。
2. 通过摸摸、喂食、玩耍和休息改变宠物状态。
3. 通过小游戏获得金币，再购买食物照顾宠物。
4. 在天气页查询当前城市或当前位置天气，让宠物给出天气提醒。
5. 在设置页开启桌面悬浮窗，或导入自定义图片、资源包和 AI 动画。
6. 在设置页的“AI 动画库”中管理历史动画版本，可切换、重命名或删除之前生成的版本。
